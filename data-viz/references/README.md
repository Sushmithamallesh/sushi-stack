# Sources

Distillations only — not reprints. Each file is one source, named for the author and venue, so a later article can land here without editing `SKILL.md` or the playbook.

When you add a source:

1. Create `references/<slug>.md` (kebab-case). Open with a short header: title, author, URL, date, and **what it is good for** (one paragraph).
2. Distill claims, examples, and trade-offs. Quote sparingly. Do not paste the article.
3. Add a row to the table below.
4. If the source changes a default in `SKILL.md` or a row in `playbooks/form-chooser.md`, make that one surgical edit and say why in the PR. Do not merge two essays into one mega-skill.

| File | Use when |
| --- | --- |
| [saloni-dattani-scientific-discovery-2025.md](saloni-dattani-scientific-discovery-2025.md) | Meaning, clarity, standalone figures, misreads, transparency — the first plate of this skill |

Further reading named by a source (not yet distilled) can sit as a bullet under that file’s “See also,” not as empty stub files.
