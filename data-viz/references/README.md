# Sources

Distillations only — not reprints. Each file is one source. Add a later article by dropping a file and a row here; do not merge essays into `SKILL.md`.

When you add a source:

1. Create `references/<slug>.md` (kebab-case). Header: title, author, URL, date, **what it is good for**.
2. Distill claims, examples, and trade-offs. Do not paste the article.
3. Add a row below (or under Skipped).
4. If it changes a default in `SKILL.md` or `playbooks/form-chooser.md`, make that one surgical edit.

Load the file that matches the snag. Do not ingest the whole folder for every chart.
