# A friendly guide to choosing a chart type

- **Author:** Lisa Charlotte Muth (Datawrapper)
- **URL:** https://www.datawrapper.de/blog/chart-types-guide
- **Date:** 2025-06-16
- **Good for:** Goal → a shortlist of forms. Ignore the rest of the zoo.

The statement of the chart is the compass. If the job is “how this changed,” you do not need pies, scatterplots, or treemaps.

## Time

- **Line** — default for continuous change (population, unemployment, temperature).
- **Small-multiple lines** — many overlapping series.
- **Area** — how a *breakdown* of a total changed (energy mix). Not for comparing one slice’s exact height.
- **Columns** — a handful of time points, or values that “fill from zero” each period (monthly sales).
- **Stacked / grouped columns** — subcategories; grouped if the comparison is *within* time, stacked if the total matters. Grouped hides totals.
- **Slope** — only start and end matter.
- **Arrow plot** — many categories, little space; slower for a general reader.
- **Stream graph** — attention, not values.

Familiar forms compare better. Use the fancy one when it earns the learning cost (or to break a run of fifteen identical lines).

## Shares

- Pie / donut / parliament: scream “this is a whole.” Angles are weak for comparison. Fine near 25/50/75%; **five slices max**.
- **Bars** for the shares people actually need to compare (election results).
- Waffle / pictogram: illustration over precision.
- **Stacked bars** for Likert / multi-item surveys.
- Marimekko: share *and* size of the whole (US column wider than Canada). Treemap: hierarchy, hard to read.

One pie = one total. Two polls → stacked bars, not two pies.

## Amounts (not shares)

- **Bars** first. Proportional-area circles/squares and pictograms are louder and less accurate.
- Stacked / split / grouped bars or columns when there are parts. Population pyramid = mirrored split bars.
- **Dot plots** when several values per category and little width.
- **Mobile:** bars grow down the page; 30 columns rotate or smash.

## Relationship, flow, place

- **Scatter** (bubbles if a third magnitude). If overlap hides the cloud, a 2D histogram/heatmap.
- Scatter is a late chart: lead with a simple claim, then the relationship.
- Flows: Sankey (volume) vs alluvial (category switches) — don’t sweat the name; do sweat whether the reader can follow.
- **Choropleth** for rates in regions; **symbol map** for many point locations; **locator** for a few places. Maps because geography is the story, not because you have a country column.

## Complexity

Escalate: one clear line → then a comparison → then the scatter. Everyone should still leave with the first sentence.
